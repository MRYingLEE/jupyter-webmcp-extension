    Runtime extensions

    Jupyter extensions can be loaded at runtime from PyPI, instead of the bundled builds. Enter the package name and version. The package's universal wheel is downloaded from PyPI, checked against the sha256 that PyPI publishes, and its JupyterLab extension is stored. A failed check stores nothing. Loaded packages start selected; clear one in the popup to stop it loading. Pages pick up changes after they reload.

    The package must ship exactly one JupyterLab extension in a py3-none-any wheel. Examples:

    • anywidget 0.11.0
    • jupyterlab-drawio 0.9.0
    • jupyterlab-execute-time 3.3.0
    • jupyterlab-code-formatter 3.1.0

    A package without a JupyterLab extension, such as numpy, is rejected.

      WebMCP settings

      JSON object with the settings of the WebMCP plugin: tools, disabledTools, blockedCommands, executionTimeout (seconds, 0 to 3600), and maxResultLength (integer, at least 1000). Invalid values fall back to the defaults. Tokens, notebook content, and outputs are never stored here.
